# Code of conduct

We want a welcoming project for people of all backgrounds and abilities. Be respectful, patient, and constructive. Accept different experiences and access needs; use inclusive language; respect people's privacy and consent. Do not demand that anyone disclose a disability, diagnosis, or personal information.

Harassment, discrimination, threats, sexualized attention, personal attacks, and publishing private information without consent are unacceptable. This applies in project spaces and when representing the project elsewhere.

Maintainers may remove content, limit participation, or block contributors when needed. For GitHub-hosted abuse or threats, use [GitHub's private reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). For other project conduct concerns, open an issue only if it is safe to do so and omit sensitive details; GitHub issues are public. No separate private maintainer contact for conduct reports is currently established.
